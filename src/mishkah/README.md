# بيئة مشكاة الرقمية — نموذج تفاعلي

نموذج واجهات تفاعلي كامل لمنصة **مركز مشكاة التعليمي** الداخلية، مبني على Next.js 16 وReact 19
ببيانات تجريبية في الذاكرة دون أي ربط خلفي أو قاعدة بيانات.

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح: <http://localhost:3000/mishkah>

في شاشة الدخول أدخل أي رقم جوال أو بريد، ثم **رمز التحقق التجريبي: `1234`**.
يمكنك أيضًا اختيار حساب تجريبي جاهز (موظف / مدير إدارة / مسؤول خدمة / مدير النظام / الإدارة العليا)
من الشرائح أسفل شاشة الدخول، أو من قائمة الحساب بعد الدخول.

## أين أعدّل؟

| ما تريد تغييره | الملف |
|---|---|
| الألوان والخطوط واسم المنصة والشعار | `src/mishkah/brand.ts` |
| ملفات الشعار | `public/mishkah/logo.png` (كامل) و`logo-mark.png` (العلامة) — والمسارات في `brand.ts` |
| مكوّنات التصميم (بطاقات، أزرار، حقول…) | `src/app/mishkah/mishkah.css` |
| الموظفون والإدارات والفرق | `src/mishkah/data/people.ts` |
| الخدمات ونماذجها ومسارات الاعتماد | `src/mishkah/data/services.ts` |
| الطلبات التجريبية | `src/mishkah/data/requests.ts` |
| منشورات الحائط | `src/mishkah/data/posts.ts` |
| اللقاءات والتقويم | `src/mishkah/data/meetings.ts` |
| الوثائق والقرارات وروابط المنصات | `src/mishkah/data/knowledge.ts` |
| الإشعارات | `src/mishkah/data/notifications.ts` |
| التسميات العربية للحالات والأدوار | `src/mishkah/selectors.ts` |

جميع البيانات تُحمّل من `src/mishkah/data/` مرة واحدة عند فتح المنصة، ثم تُدار في الذاكرة عبر
`src/mishkah/store.tsx`. تحديث الصفحة (Refresh) يعيد البيانات إلى حالتها الأولى، وكذلك زر
**«إعادة البيانات التجريبية»** في قائمة الحساب.

## بنية الملفات

```
src/mishkah/
  brand.ts              هوية المنصة (ألوان، خطوط، شعار، نصوص عامة)
  types.ts              أنواع البيانات
  store.tsx             حالة المنصة وجميع الإجراءات التفاعلية
  selectors.ts          التسميات العربية وأدوات الصلاحيات
  remember.ts           مخزن «تذكّر هذا الجهاز»
  data/                 البيانات التجريبية
  ui/                   مكوّنات أساسية (بطاقة، وسم، نافذة، تبويب…)
  components/           مكوّنات الأقسام (الحائط، النموذج الذكي، الشل…)
src/app/mishkah/
  layout.tsx            غلاف المنصة + شاشة الدخول + التنقل
  mishkah.css           نظام التصميم
  page.tsx              مجتمع مشكاة (الصفحة الرئيسة)
  office/               مكتبي (طلباتي، صندوق الإجراءات، الملف الشخصي)
  services/             دليل الخدمات وبطاقة الخدمة ونموذج التقديم
  units/  teams/        الإدارات والفرق واللجان
  knowledge/            معرفة مشكاة والقرارات
  calendar/             التقويم واللقاءات
  directory/            دليل الموظفين
  notifications/        مركز الإشعارات
  admin/                لوحة مدير النظام
  insights/             لوحة المؤشرات
```

## الشاشات المنفَّذة

1. شاشة الدخول (معرّف ← رمز تحقق ← تذكّر الجهاز).
2. مجتمع مشكاة: ترحيب، ملخص اليوم، اختصارات، حائط تفاعلي بتصفية، لقاءات، قرارات، طلبات، موظفون جدد، منجزات.
3. مكتبي: طلباتي (بطاقات/قائمة/جدول)، مطلوب مني، تقويمي، المسودات، إدارتي وفرقي ومنصاتي.
4. صندوق الإجراءات (لمدير الإدارة ومسؤول الخدمة).
5. تفاصيل الطلب: التقدم، التفاصيل، المرفقات، سجل الإجراءات، أزرار الاعتماد والرفض والإعادة والتحويل والتنفيذ والإغلاق.
6. دليل الخدمات + بطاقة الخدمة + النموذج الذكي متعدد الخطوات مع المعاينة.
7. إدارات وفرق مشكاة + صفحة الإدارة + مساحة الفريق أو اللجنة.
8. معرفة مشكاة + صفحة القرار مع «اطلعت على القرار» وسجل الاطلاع.
9. التقويم الموحّد + صفحة اللقاء مع تأكيد الحضور والاعتذار والمحضر.
10. دليل الموظفين + الملف التعريفي للزميل.
11. مركز الإشعارات المصنّف.
12. لوحة مدير النظام (إدارات، فرق، موظفون، صلاحيات، خدمات، إعلانات، أقسام الصفحة الرئيسة، تقارير).
13. لوحة المؤشرات للإدارة العليا.
14. البحث الشامل (موظف / خدمة / وثيقة / لقاء / إدارة).
